Why on-premise — architecture overview

Industrial images, manuals, reports and specifications are processed on this workstation. The intended production stack uses local VLM / LLM / embedding runtimes. This build uses local adapters — heuristic vision and lexical retrieval — and calls no external AI APIs. Physical network isolation is a deployment configuration, not something this console can certify.
